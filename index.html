CONCEPT GUIDE

Problem vs solution

A booking is a read–modify–write operation. Without coordination, concurrent agents can observe stale state.

OPERATING SYSTEMS THEORY

Key terms

Race condition

Outcome depends on the timing of unsynchronized accesses to shared state.

Critical section

Code that accesses shared data and must execute with mutual exclusion.

Mutex

A binary ownership lock: one agent holds it; others wait until signal releases it.

Counting semaphore

A non-negative permit count. empty tracks free slots; full tracks queued requests. A binary semaphore is limited to 0 or 1.

Bounded buffer

A finite FIFO queue shared by request producers and booking consumers.

LAB RESULT

Three mechanisms, one safe reservation flow

Semaphores make producers wait when the request queue is full and consumers sleep on an empty queue. A mutex protects the queue and shared seat map from simultaneous updates. Together, they preserve requests, seat assignments, and the available-seat counter.
